# CS-330
CS 330 Computer Graphics and Visualization Portfolio 

How Do I Approach Designing Software?

Working on this project helped me improve my ability to plan a 3D scene before building it. I learned how basic shapes can be combined and changed to represent real objects. My design process started with choosing the objects I wanted in my scene and deciding which shapes would work best for each one. I then worked on the size, position, color, and texture of each object. I tested my changes as I worked instead of trying to complete everything at once. In future projects, I can use this same process by breaking a larger project into smaller parts and testing each part before moving forward.

How Do I Approach Developing Programs?

While developing my 3D scene, I learned that testing and making small changes can make programming easier. I used different coordinates, rotations, scales, colors, textures, and lighting to create the scene I wanted. Iteration was important because my scene did not look correct on the first try. I had to run the program, look at the results, make changes, and test it again. As I completed each milestone, I became more comfortable finding problems and correcting them. By the end of the project, I had a better understanding of how several pieces of code work together to create a complete 3D scene.

How Can Computer Science Help Me Reach My Goals?

Computer graphics and visualization gave me experience with programming in a way that I had not used before. I learned more about creating objects, working with coordinates, applying textures, controlling lighting, and using a camera in a 3D environment. These skills can help me in future computer science courses because I now have more experience solving problems through code. Professionally, this project also helped me practice patience, troubleshooting, and attention to detail. These are skills that can be useful in software development because programs often require testing and improvements before they work as expected.
